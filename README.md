
## Project Summary

Imagine changing a line of code and finding out later that another part of the project stopped working. This small learning repository focuses on continuous integration, which means checking code changes through repeatable steps.

The idea is to run automated checks when a project changes, rather than testing everything manually each time. For example, a failed test can warn you before new code is treated as ready. I explored why automatic checks are useful when working on software and machine learning projects. The original README contains very little implementation detail.
